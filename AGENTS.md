# Workspace Guidelines & Rules

## Git Workflow
- **Auto-Commit & Push by Default**: Whenever a coding task, bug fix, refactor, or feature change is completed, automatically stage (`git add`), commit with a descriptive message (`git commit`), and push to GitHub (`git push origin main`).
- **Clean Commits**: Ensure sensitive secrets (`.env`), temporary logs, and build artifacts remain excluded in `.gitignore`.
